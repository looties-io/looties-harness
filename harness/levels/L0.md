# Level L0

Summary of [the levels](../../docs/agent-harness.md#difficulty-levels); the standard wins on conflict.

- For small changes with one obvious correct form and no L2 trigger.
- Announce `Level L0: <reason>`, then act, verify, commit and push the feature branch.
- Never push to the release branch. Arm auto-merge only when the maintainer's opening instruction for the task grants it with a line of its own reading `auto-merge allowed`, as `gh pr merge <number> --auto --merge --delete-branch --match-head-commit <sha>` once the review below approved that head. Merge into the integration branch with `gh pr merge <number> --merge --delete-branch --match-head-commit <sha>` only after an [independent review](../../docs/agent-harness.md#independent-review) by a `reviewer` subagent of this session approved that exact head commit and checks are green; otherwise stop at `gh pr ready`.
- Push directly to the integration branch only a commit a `reviewer` subagent of this session approved, as a fast-forward with `git push origin <sha>:refs/heads/<integration branch>`; require dispatched CI, or for eligible docs-only pushes a clean tree and a clean docs check when one is configured ([conditions](../../docs/agent-harness.md#direct-push-to-the-integration-branch)).
- Production commands still ask every time. A user-visible change still needs a validated mockup first.
- Raise to L1 or L2 as soon as the work stops being small or hits an L2 trigger.
